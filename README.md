# Creator Reward Claim Website

A professional, mobile-friendly reward claim website for promotional campaigns.

## Features

- ✅ Responsive landing page with campaign details
- ✅ Secure claim form with validation
- ✅ Review page with shipping fee disclosure ($120)
- ✅ Paystack payment integration (supports USD)
- ✅ Claim confirmation with unique reference number
- ✅ Email notification system
- ✅ Supabase database integration
- ✅ Rate limiting and security features
- ✅ GDPR/Privacy compliant
- ✅ Ready for production deployment

## Tech Stack

- **Backend:** Flask (Python)
- **Database:** Supabase (PostgreSQL)
- **Payment:** Paystack
- **Email:** SendGrid/SMTP
- **Deployment:** Docker, Gunicorn, Nginx
